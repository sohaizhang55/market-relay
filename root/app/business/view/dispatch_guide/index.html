2. 对接流程

  1. 握手请求头带 X-Inner-Token: <本订阅方 token>：分发鉴权开启后不带或带错，握手直接回 HTTP 403，连接建不起来；未开启时可不带，但带上才能在后台看到你的最后连接 IP
  2. 连上对应端口（现货 / 合约各一个），连上后先发 hello（文本帧），不发一帧都收不到
  3. hello 通过后，分发机先按订阅补发一次当前快照，之后某个 stream 一有变化就推一条
  4. 行情是二进制帧：一条消息 = 一帧，内容是 raw deflate 压缩的 JSON，第一个字段是 stream
  5. 文本帧都是系统帧（_sys 开头）：收到 ping 要回 pong，否则会被断开（超时见第 6 节）
  6. 断线后重连、重新发 hello 即可：覆盖语义下补一次快照就是最新状态，不需要补中间的历史
  7. 想改订阅就再发一次 hello，整个替换旧订阅（不是增量），并重新补快照

8. 收数示例

        
JavaScript（Node，npm install ws pako；浏览器的 WebSocket 设不了请求头，不能用）

{literal}

const WebSocket = require('ws'), pako = require('pako');
const ws = new WebSocket('ws://<分发机IP>:{/literal}{$exampleSwapPort}{literal}', { headers: { 'X-Inner-Token': '<token>' } });
ws.binaryType = 'arraybuffer';
ws.onopen = () => ws.send(JSON.stringify({ cmd: 'hello', node: 'server-b', streams: ['btcusdt@ticker', 'btcusdt@depth@500ms'] }));
ws.onmessage = (ev) => {
  if (typeof ev.data === 'string') {                       // 文本帧 = 系统帧
    const m = JSON.parse(ev.data);
    if (m._sys === 'ping') ws.send(JSON.stringify({ _sys: 'pong', ts: m.ts }));
    else console.log('sys', m);                            // error / throttle
    return;
  }
  const frame = JSON.parse(pako.inflateRaw(new Uint8Array(ev.data), { to: 'string' }));
  console.log(frame.stream, frame);                        // 按 frame.stream 分发处理
};

{/literal}
        
Python（pip install websockets）

{literal}

import asyncio, json, zlib, websockets

async def main():
    async with websockets.connect("ws://<分发机IP>:{/literal}{$exampleSwapPort}{literal}", max_size=None,
                                  additional_headers={"X-Inner-Token": "<token>"}) as ws:
        await ws.send(json.dumps({"cmd": "hello", "node": "server-b", "streams": ["btcusdt@ticker"]}))
        async for msg in ws:
            if isinstance(msg, str):                        # 文本帧 = 系统帧
                m = json.loads(msg)
                if m.get("_sys") == "ping":
                    await ws.send(json.dumps({"_sys": "pong", "ts": m["ts"]}, separators=(",", ":")))
                else:
                    print("sys", m)
                continue
            frame = json.loads(zlib.decompress(msg, -15))   # raw deflate
            print(frame["stream"], frame)

asyncio.run(main())

{/literal}
        
用 Postman / PieSocket 这类工具手连也可以：地址要写全 ws://，发 hello 后能看到系统帧，行情帧是二进制（显示为乱码属正常），并且要每 30 秒左右手动发一次 {"_sys":"pong","ts":0}。
